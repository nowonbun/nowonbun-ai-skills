# work-runtime 스킬 설명

## 목적
- `work-runtime`은 AGENTS가 위임한 공통 runtime 제어 문서다.
- exact trigger 우선순위, 공통 MCP 사전 검증, 공통 중단 조건, 공통 보고 형식, UTF-8 검증을 담당한다.

## 담당 범위
- 읽기 작업, 안전한 로컬 변경, 외부·파괴적 변경의 실행 경계를 구분한다.
- 작업 위험에 맞는 로컬 검증과 최소 보고 형식을 정의한다.

## 사용 시 주의
- workflow별 세부 실행 순서를 이 문서에 직접 넣지 않는다.
- 텍스트 문서는 UTF-8로 저장하고 파일 기준으로 검증한다.
